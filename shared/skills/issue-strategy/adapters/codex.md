# Issue strategy for Codex

Use the current user request as the decision question. Read and follow
[the shared workflow](WORKFLOW.md) before analyzing, then load the relevant
references or the optional GitHub collector from this skill directory.

Honor the selected workspace's AGENTS.md and provider/credential constraints.
Use the available tools within existing permissions, preserve dirty work and
keep private evidence outside publishable repositories. Where company source
requires an approved company model, use that route rather than sending source
to a personal provider.

Deliver a proposed decision brief with source coverage, uncertainty, alternatives
and measurable next steps. An analysis request does not automatically authorize
implementation, issue mutation, delegation or persistent policy/memory updates.
Retain authority for any additional actions the user explicitly requested.
